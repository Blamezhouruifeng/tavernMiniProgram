### 小程序端（uniapp）

- 扫码进桌（桌码 `scene=t=桌号`）→ 同一桌共用会话；二次扫码回到原会话
- 菜单（分类/规格/沽清标注/预计制作时长）→ 规格弹层加购
- **全桌共享**：本桌已点吸顶栏 + 按菜聚合弹层（谁点的、已上几份）
- 购物车：**每人一个篮子**，别人的只读；提交**只清自己已下单的行**
- 先付制：提交订单 → 待支付倒计时 → 支付成功即「制作中」→ **行级**制作进度
- 存酒：剩余量进度条、储位、瓶签码、动态取酒码（30 秒自动刷新）
- 员工工作台：出票区、桌台看板（呼叫/转台/清台）、核销、代存登记、沽清
- 会员中心：手机号绑定、员工入口按 `is_staff` 显示

### 后台（hotgo/web）

门店配置 / 桌位 / 商品分类 / 商品与规格 / 订单查询 / 存酒台账，共 6 个页面，已在侧边栏「酒馆管理」下注册（菜单 ID 2432–2438）。

## 2. 本地运行

```bash
# 1) 数据库（首次）
mysql -uroot -p tavernMiniProgram < hotgo/server/storage/data/tavern_mvp.sql
mysql -uroot -p tavernMiniProgram < hotgo/server/storage/data/tavern_menu.sql   # 后台菜单

# 2) 后端（:8000）
cd hotgo/server && go run main.go
#   Swagger: http://127.0.0.1:8000/swagger/
#   小程序接口前缀: http://127.0.0.1:8000/api/tavern

# 3) 后台（:8001）
cd hotgo/web && pnpm dev

# 4) 小程序端
cd uniapp && pnpm dev:h5        # 或 pnpm dev:mp-weixin
```

小程序端接口地址在 `uniapp/.env.development` 的 `VITE_API_BASE_URL`（当前 `http://127.0.0.1:8000/api`）；
`VITE_USE_MOCK=true` 可切回离线 mock 调试。
